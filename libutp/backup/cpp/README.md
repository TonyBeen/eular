# C++ Implementation

The archived C++ implementation lives here:

- `include/`: installed C++ library headers
- `src/`: implementation and private headers
- `test/`: C++ unit, integration, and fault-injection tests
- `examples/`: C++ example programs

The repository root no longer builds this implementation. The C11 production
implementation lives in `utp/` and is the only default library target.

The archived files are retained for protocol history and comparison only; use
the `utp/` build for current development and testing.
